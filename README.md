# 🎩 Монополія Україна — Telegram Mini App (WebSocket)

## Запуск
1. Встановіть Node.js 18+.
2. У папці проєкту виконайте `npm install` та `npm start`.
3. Відкрийте `http://localhost:3000` для локального тестування.
4. Для Telegram розгорніть Node.js застосунок на хостингу з постійним процесом, HTTPS і підтримкою WebSocket (WSS). Вкажіть публічну HTTPS-адресу в BotFather як Mini App. **GitHub Pages самостійно не запускає Node.js сервер.**
5. У кімнаті організатор створює гру, інші приєднуються за кодом або посиланням. Почати можна з 2 гравцями.

## Функції MVP
40 клітинок, 2–6 гравців, 4 режими, купівля об'єктів, оренда, податки, події, хід кубиками, банкрутство, переможець, мобільний інтерфейс.

## Обмеження (важливо)
Це **демо-прототип**, не готовий публічний реліз. Дані зберігаються лише в пам'яті процесу й зникають після перезапуску. Перепідключення до поточної гри не підтримується; відключений гравець може зупинити партію. Ідентифікація Telegram на сервері ще не перевіряється криптографічно через initData; кімнати захищені лише кодом. Немає будинків, готелів, аукціонів, обмінів, застав, повноцінних карток подій, таймера та офіційної логіки в'язниці. Правила — спрощена авторська адаптація, а не повна класична Monopoly.

## Безпека для релізу
Додати серверну перевірку Telegram initData за токеном бота, авторизацію кімнат, обмеження запитів, постійне сховище (SQLite/Postgres), відновлення сесій, таймери та аудит правил гри. Не публікувати токен бота у клієнтському JavaScript.
