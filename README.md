# Монополія Україна 4.3 — UI redesign

Статичний Telegram Mini App для GitHub Pages. Завантажте index.html, style.css, app.js до кореня репозиторію monopolia. Firebase: monopoly-fc387. У Firebase Authentication увімкніть Anonymous, у Realtime Database застосуйте правила лише для приватного тестування.

Версія 4.3 змінює інтерфейс, зберігає базову ігрову логіку 4.2. Це не завершена захищена гра: немає серверної перевірки ходів, будівництва, обмінів, аукціонів, гарантованого відновлення гравця після повторної анонімної авторизації. У браузері поза Telegram ім'я за замовчуванням «Гравець». Не використовуйте тестові правила Firebase для публічного релізу.
