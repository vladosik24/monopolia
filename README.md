# 🎩 Монополія Україна — Telegram Mini App (MVP)

## Що працює
- Квадратне поле на 40 клітинок, українські міста, 2–6 гравців.
- Режими: Класичний, Швидкий, Багатій, Хардкор.
- Онлайн-кімнати за кодом, запрошення посиланням, ходи, кубики, купівля, оренда, податки, події, в'язниця, банкрутство, перемога.
- Firebase Realtime Database transactions для уникнення випадкової одночасної перезапису ходів.

## Запуск
1. У Firebase Console для проєкту `monopoly-ukraine` увімкніть Authentication → Sign-in method → **Anonymous**.
2. У Firebase Realtime Database → Rules встановіть правила з `database.rules.json` і натисніть Publish. **Увага: ці правила лише для тестування.**
3. Розмістіть `index.html`, `style.css`, `game.js`, `config.js` у корені репозиторію GitHub Pages (HTTPS).
4. Відкрийте HTTPS URL в браузері. Для Telegram Mini App в @BotFather задайте Menu Button URL або створіть кнопку `web_app` із цим HTTPS URL.
5. Для тестування двох гравців відкрийте сторінку на різних пристроях або у різних профілях браузера, створіть кімнату і введіть код на другому пристрої.

## Важливі обмеження
- **Це MVP, не захищений продакшн.** Вся логіка, включно з генерацією кубиків і грошовими транзакціями, наразі виконується на клієнті. Модифікований клієнт може підміняти стан кімнати. Firebase rules обмежують доступ лише базово і НЕ перевіряють законність ігрових ходів. Перед публічним запуском перенесіть ходи в Cloud Functions / власний бекенд, перевіряйте Telegram `initData` на сервері, увімкніть App Check, rate limits та належні security rules.
- Anonymous Firebase UID не дорівнює перевіреній Telegram-особі. В браузері профіль може бути втрачено після очищення сховища.
- Наразі немає будинків, готелів, аукціонів, обміну, застав, дубля на кубиках, класичного набору карток та повного набору правил. Картки «Шанс» спрощені, а назви та ціни міст авторські.
- Для кімнат у цій версії немає автоматичного видалення або повернення гравця після банкрутства.
- Створення кімнати доступне лише за умови правильно налаштованої Firebase Authentication та Database.

## Файли
- `index.html` — розмітка та SDK
- `style.css` — адаптивний інтерфейс
- `game.js` — клієнтська логіка гри
- `config.js` — налаштування Firebase
- `database.rules.json` — базові тестові правила доступу
