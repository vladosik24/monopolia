# Монополія Україна 4.1 — Міста та Імперії

Мобільний Telegram Mini App на HTML/CSS/JavaScript + Firebase Realtime Database, без Node.js.

## Запуск
1. У Firebase Console проєкту `monopoly-fc387` відкрийте Authentication → Sign-in method → Anonymous → Enable.
2. Створіть/увімкніть Realtime Database за адресою, вказаною в `app.js`.
3. Для ЗАКРИТОГО ТЕСТУ вставте `database.rules.json` у Realtime Database → Rules → Publish.
4. Завантажте `index.html`, `style.css`, `app.js` до кореня репозиторію GitHub Pages (наприклад `/monopolia/`).
5. Відкрийте HTTPS-посилання або налаштуйте його як Telegram Mini App у @BotFather.
6. На двох пристроях створіть кімнату, приєднайтеся за кодом і почніть гру.

## Можливості MVP
- Оригінальний темно-синій/золотий дизайн, головне лобі, список відкритих кімнат, приватні кімнати, запрошення.
- 40 клітинок, власні назви районів і підприємств, 2–6 гравців, 4 режими.
- Кубики, хід, купівля, оренда, зарплата, податки, події, банкрутство, переможець.
- Транзакції Firebase для уникнення одночасних конфліктуючих записів.

## ВАЖЛИВО: обмеження безпеки
Ці правила дозволяють **будь-якому анонімно авторизованому користувачу змінювати будь-яку кімнату**. Вони призначені ВИКЛЮЧНО для тестування з довіреними людьми. Для публічного релізу потрібно серверно перевіряти Telegram initData, кубики, економіку, власника кімнати, черговість ходів і дозволені переходи стану (Cloud Functions / власний сервер). Клієнтські транзакції не є захистом від шахрайства.

## Ще не реалізовано
Будинки/готелі, аукціони, обміни, чат, рейтинги, аватарки інших гравців, відновлення анонімного профілю після очищення даних браузера, окрема панель адміністратора, античит. Учасник, що закрив застосунок, залишається у партії; таймер пропуску ходів ще не додано.

## Примітка
Firebase `apiKey` — публічний ідентифікатор клієнтського застосунку, а не серверний секрет. Не додавайте до репозиторію service account credentials.
