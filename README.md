# Монополія Україна — Pixel Edition (MVP)

## Встановлення
1. Завантажте вміст папки `public/` у корінь GitHub Pages репозиторію `monopolia`.
2. Firebase Console → проєкт `monopoly-fc387` → Authentication → Sign-in method → Anonymous → Enable.
3. Realtime Database → Rules → вставте вміст `database.rules.json` та опублікуйте. **Ці правила лише для приватного тестування!** Вони дозволяють будь-якому анонімно авторизованому клієнту змінювати чужі партії, підробляти кидки й баланси. Не використовуйте для публічного релізу, призів чи реальних платежів.
4. Відкрийте HTTPS-адресу GitHub Pages, створіть кімнату, з іншого пристрою увійдіть за кодом. Власник запускає гру після приєднання другого гравця.
5. У BotFather вкажіть HTTPS-адресу як URL Mini App.

## Що працює
- 40 клітинок, квадратне поле, піксельне оформлення UI, 2–6 гравців, кімнати Firebase, 4 режими зі стартовими балансами.
- Кидок двох кубиків з CSS-анімацією, черговість ходів, переміщення фішок, купівля, оренда, зарплата, податки, випадкові бонуси/штрафи, банкрутство, переможець.
- Спільний чат і події, звуковий ефект кубика (Web Audio), перегляд майна.

## Що не реалізовано
- 40 окремих згенерованих ілюстрацій: наразі стилізовані клітинки з піктограмами. Піксельний фон зроблено CSS.
- Будівництво, обміни, аукціони, відновлення автентичності Telegram-профілю, серверний захист ходів, рейтинги, повноцінна музика.
- Ігрова логіка виконується в браузері; Firebase транзакції захищають від одночасного перезапису, але **не від шахрайства**. Для релізу потрібна серверна перевірка дій і Telegram initData.

## Структура
- `public/index.html`, `public/style.css`, `public/app.js` — статичний клієнт.
- `database.rules.json` — тестові правила Realtime Database.
