# Монополія Україна 4.5 — тестовий прототип

Розмістіть усі файли в корені репозиторію GitHub Pages. `index.html`, `app.js`, `style.css`, `audio.js`, папку `art/`.

Firebase проєкт: `monopoly-fc387`. Увімкніть Authentication → Anonymous і Realtime Database. Правила в `database.rules.json` призначені **лише для приватного тестування**: будь-який анонімно авторизований клієнт може змінити стан кімнати. Це НЕ захищений онлайн-реліз.

Функції: 2–6 гравців, 4 режими, 40 клітинок, онлайн-кімнати, кидання кубиків, купівля, оренда, будівництво до 4 будинків і готелю, продаж майна іншому гравцеві за погодженою ціною, чат і події, синтезовані музика й ефекти. Графіка клітинок — 40 SVG-ілюстрацій. Графіка не є копією іншої гри.

Обмеження: анонімна Firebase-ідентифікація не прив'язана криптографічно до Telegram; серверної валідації кубиків, грошей, угод немає. Випадковість визначається клієнтом. Не використовувати з реальними платежами. Немає аукціонів, кланів, турнірів і стійкого профілю між пристроями. Не протестовано на декількох реальних телефонах.
