# Монополія Україна 4.2 — Міста та Імперії

## Встановлення
1. Завантажте `index.html`, `style.css`, `app.js` у корінь GitHub Pages репозиторію `monopolia`.
2. Firebase project: `monopoly-fc387`. У Authentication → Sign-in method увімкніть Anonymous.
3. У Realtime Database → Rules налаштуйте правила. Файл `database.rules.json` — **ЛИШЕ ДЛЯ ЗАКРИТОГО ТЕСТУ**: кожен анонімно авторизований користувач може змінювати кімнати. Для публічного релізу потрібні серверна перевірка ходів та захищені правила.
4. Відкрийте https://vladosik24.github.io/monopolia/ і створіть кімнату, запросіть друга.

## Що нового у 4.2
- Новий преміальний інтерфейс лобі та поля, адаптація під телефон.
- Центральні вкладки «Події» / «Чат» з повідомленнями в кімнаті.
- Відображення активного гравця, власності, кнопки «Моє майно» та «Правила».
- Збережено базові механіки 4.1: кімнати 2–6, 4 режими, кубики, купівля, оренда, податки.

## Обмеження
- Це тестовий прототип. Будинки, обміни, аукціони, рейтинг, магазин та інвентар ще не реалізовано.
- Кубики та ігрові транзакції обчислюються на клієнті: можливі маніпуляції.
- Довгі назви клітинок на вузьких екранах дуже дрібні; масштабування і zoom поля — наступний крок.
- Перевірте багатокористувацьку гру на двох телефонах перед використанням.
