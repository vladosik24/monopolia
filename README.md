# Монополія Україна 4.4 — тестове мультимедійне оновлення

Завантажте вміст архіву до кореня GitHub Pages `monopolia`. Потрібні Firebase Anonymous Authentication і Realtime Database, як у 4.3.

Нові функції: спільна стрічка чату й подій, анімація двох кубиків, звукові ефекти та оригінальна синтезована фонова мелодія (Web Audio API), регулювання гучності, 40 **окремих авторських векторних ілюстрацій** клітинок, ілюстрований фон. Це не фотографії; для фотореалістичних ілюстрацій потрібна окрема генерація 40 зображень.

Застереження: це клієнтський Firebase-прототип. Випадковість кубиків і дії гравців не захищені серверною перевіркою. Не використовуйте для гри на реальні гроші.

Музика запускається після натискання кнопки. У Web Audio немає сторонніх музичних творів чи авторських семплів.
